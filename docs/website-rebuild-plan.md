# 个人网站改造方案（第一版）

## 1. 改造目标

- 从单文件页面升级为可维护的多页面结构。
- 保留现有复古视觉风格，同时提升可读性、可扩展性与可访问性。
- 建立前端新手也能持续维护的目录与数据组织方式。

## 2. 当前问题

- 页面逻辑、内容、样式全部堆在 `src/App.vue`，后续改动成本高。
- 路由已初始化但未配置有效页面。
- 内容为硬编码，无法快速增删作品。
- SEO 基础信息不足，仅有 title。
- README 仍是模板文档，不利于后续协作和自我维护。

## 3. 本次改造范围（已同意执行）

### 3.1 架构改造

- 引入页面级路由：主页、关于、作品、404。
- 使用布局壳层 `App.vue` + `RouterView`。

### 3.2 组件与数据改造

- 新建可复用头部导航组件。
- 将站点信息和作品列表抽离为独立数据文件。
- 主页只负责展示，数据与结构解耦。

### 3.3 体验与基础规范

- 完善 `index.html` 的 SEO 元信息。
- 优化基础可访问性（语义化、焦点状态、aria 标签）。
- 保留并增强当前响应式表现。

## 4. 目录规划

```text
src/
  components/
    SiteHeader.vue
  data/
    site.ts
  views/
    HomeView.vue
    AboutView.vue
    ProjectsView.vue
    NotFoundView.vue
  router/
    index.ts
  App.vue
  main.ts
```

## 5. 验收标准

- 访问 `/`、`/about`、`/projects` 可正常显示。
- 访问不存在路由进入 404 页面。
- 首页结构拆分完成，`App.vue` 不再承载全部业务内容。
- 构建命令 `npm run build` 通过。

## 6. 下一阶段建议（本次不做）

- 增加作品详情页（动态路由）。
- 引入文章系统（Markdown 驱动）。
- 接入访问统计与联系表单服务。
- 做 Lighthouse 指标优化与上线清单。
