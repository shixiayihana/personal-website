# A 股分位观测站宝塔计划任务部署指南

本文适用于服务器目录：

```text
/www/wwwroot/www.11251236.xyz/personal-website
```

爬虫代码位于：

```text
backend/crawler/fetch_val.py
```

## 一、目录和文件关系

Git 拉取代码后，目录应至少包含：

```text
personal-website/
├── backend/
│   ├── common/
│   │   ├── __init__.py
│   │   ├── db_config.py
│   │   └── settings.py
│   ├── crawler/
│   │   ├── __init__.py
│   │   ├── fetch_val.py
│   │   └── requirements.txt
│   ├── .env                 # 服务器手动创建，不提交 Git
│   ├── requirements.txt
│   └── init.sql
├── frontend/
└── logs/
    ├── web/
    └── crawler/
```

`backend/.venv` 不会从 Git 拉取，因为它在 `.gitignore` 中。服务器需要单独创建一次。

## 二、首次部署

### 1. 进入后端目录

```bash
cd /www/wwwroot/www.11251236.xyz/personal-website/backend
```

### 2. 创建虚拟环境

服务器已安装 Python 3 后执行：

```bash
python3 -m venv .venv
```

如果提示没有 `venv` 模块，需要先通过系统包管理器安装对应的 Python venv 包。

### 3. 安装依赖

```bash
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
```

### 4. 创建数据库环境变量文件

```bash
cp .env.example .env
vi .env
```

至少填写：

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=cn_index_percentile_app
DB_PASSWORD=真实数据库密码
DB_NAME=cn_index_percentile
```

限制文件权限：

```bash
chmod 600 .env
```

数据库表需要提前执行 `backend/init.sql`，程序不会自动建表。

### 5. 创建日志目录

```bash
mkdir -p /www/wwwroot/www.11251236.xyz/personal-website/logs/crawler
```

## 三、手动测试爬虫

必须在 `backend` 目录执行模块命令。不要在 `backend/crawler` 目录直接执行 `python3 fetch_val.py`，否则可能找不到同级的 `common` 包。

### 只请求和校验，不写数据库

```bash
cd /www/wwwroot/www.11251236.xyz/personal-website/backend
.venv/bin/python -m crawler.fetch_val --dry-run
```

预期输出类似：

```text
校验完成，未写入数据库：data=2026-09-11
SH000300 沪深300: PE=..., PB=...
SH000905 中证500: PE=..., PB=...
SZ399006 创业板: PE=..., PB=...
```

### 正式写入数据库

```bash
.venv/bin/python -m crawler.fetch_val
```

重复执行不会为同一个指数和日期创建重复记录，会更新已有估值数据。

## 四、宝塔计划任务命令

在宝塔面板进入“计划任务”，选择“Shell 脚本”，设置每天 22:00 执行。

脚本内容：

```bash
#!/usr/bin/env bash
set -Eeuo pipefail

PROJECT_DIR=/www/wwwroot/www.11251236.xyz/personal-website
BACKEND_DIR="$PROJECT_DIR/backend"
PYTHON="$BACKEND_DIR/.venv/bin/python"
LOG_DIR="$PROJECT_DIR/logs/crawler"
LOG_FILE="$LOG_DIR/fetch-$(date +%F).log"

cd "$BACKEND_DIR"

if [ ! -x "$PYTHON" ]; then
    echo "[$(date '+%F %T')] Python 虚拟环境不存在：$PYTHON" >&2
    exit 1
fi

exec "$PYTHON" -m crawler.fetch_val >> "$LOG_FILE" 2>&1
```

这里使用：

```bash
cd "$BACKEND_DIR"
"$PYTHON" -m crawler.fetch_val
```

以下命令不要执行，它们分别对应错误的当前目录、错误的文件位置或错误的绝对路径：

```bash
python3 fetch_val.py
python3 backend/fetch_val.py
python3 /crawler/fetch_val.py
```

原因是实际脚本在 `backend/crawler/fetch_val.py`，且它需要从 `backend` 目录导入 `common` 包。

## 五、设置补偿任务

建议再创建一个相同脚本的计划任务，每天 23:00 执行。两次任务使用相同的命令和幂等写入逻辑。

如果希望使用同一个脚本文件，也可以保存为：

```text
/www/wwwroot/www.11251236.xyz/personal-website/deploy-crawler.sh
```

并在计划任务中执行：

```bash
/bin/bash /www/wwwroot/www.11251236.xyz/personal-website/deploy-crawler.sh
```

## 六、查看执行日志

查看当天日志：

```bash
tail -n 100 /www/wwwroot/www.11251236.xyz/personal-website/logs/crawler/fetch-$(date +%F).log
```

实时查看日志：

```bash
tail -f /www/wwwroot/www.11251236.xyz/personal-website/logs/crawler/fetch-$(date +%F).log
```

## 七、Git 更新后的操作

如果只是 Python 代码更新：

```bash
cd /www/wwwroot/www.11251236.xyz/personal-website
git pull --ff-only
```

如果 `requirements.txt` 有变化，重新安装依赖：

```bash
cd backend
.venv/bin/python -m pip install -r requirements.txt
```

如果计划任务提示 `No such file or directory`，依次检查：

```bash
test -f /www/wwwroot/www.11251236.xyz/personal-website/backend/crawler/fetch_val.py && echo crawler-ok
test -x /www/wwwroot/www.11251236.xyz/personal-website/backend/.venv/bin/python && echo python-ok
test -f /www/wwwroot/www.11251236.xyz/personal-website/backend/.env && echo env-ok
```

如果提示 `No module named common`，检查当前目录：

```bash
cd /www/wwwroot/www.11251236.xyz/personal-website/backend
pwd
.venv/bin/python -m crawler.fetch_val --dry-run
```
